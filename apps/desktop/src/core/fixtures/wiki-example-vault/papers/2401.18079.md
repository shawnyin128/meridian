## 这篇说了什么
长上下文下 KV cache 成为内存主项;现有方法在 4-bit 以下失真,本文用四个手段做低比特 KV 量化。(p.1)

## 机制
Key 逐通道量化;RoPE 之前量化 Key;逐层敏感度加权的非均匀格点;逐向量的 Dense-and-Sparse 离群值隔离。(p.1)

## 主要结果
3-bit 下困惑度退化 <0.1;LLaMA-7B 单卡 100 万上下文、8 卡 1000 万;自定义 CUDA kernel 至多 ~1.7x 提速。(p.1)
